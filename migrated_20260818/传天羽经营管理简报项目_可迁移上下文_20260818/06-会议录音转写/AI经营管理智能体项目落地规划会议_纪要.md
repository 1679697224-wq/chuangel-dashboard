# AI经营管理智能体项目落地规划会议 · 纪要

> 来源：biji 分享录音（share 链接 5JwR7OrNJkNWg），完整逐字稿见同目录《AI经营管理智能体项目落地规划会议_逐字稿.md》。
> 说明：本录音与《02-核心源资料/零售企业经营管理框架与AI应用工作部署会议纪要.docx》（2026-08-17）为同一场会议的不同侧重点记录，本纪要补充老板的「五步落地规划」和智能体架构细节，作为会议纪要的延伸来源。

## 一、会议背景与目标

- 老板主讲，面向苹果产品线团队（其中 3 名为 AI 智能体搭建落实责任人）。
- 目标：把经营管理简报从「表格」推进到「AI 经营管理智能体」落地，分五步走。
- 强调：苹果原有的管理体系本身很细很清楚，不要推倒重来，在原有基础上补充想要的模块即可；不许把逻辑搞偏。

## 二、老板的「五步落地规划」（本会议核心）

1. **第一步：确定报表格式、内容、呈现形式**
   - 先定公司层面的报表格式：日报、周报、月报统一「三层结构」。
   - 老板要求看到：核心公司的核心数据（销售额、毛利等）→ 各板块具体数据和过程指标 → 重点工作跟进和每日关注的风险点。
2. **第二步：确定数据来源与获取周期**
   - 明确哪些数据日取、周取、月取、年汇总；核心是日报和周报。
   - 数据主抓三类：销售、采购、库存；返利、费用不在此列（另行处理）。
   - 取数频率：一天一次即可，不要高频轮询。
3. **第三步：使用 AI 工具，确定取数与确认流程**
   - 确定用什么工具抓取（录音提到 Codex/GPT、小龙虾项目、workflow 等候选）。
   - 抓取的数据必须有人工审核确认流程，不是纯自动抓取。
4. **第四步：搭建 AI 经营管理智能体思维框架**
   - 职能层级（当前先做四层，未来可增）：销售职能 / 运维相关 / 人事行政相关 / 财务审计风控相关。
   - 销售职能体是总职能体，下面按业务板块挂小智能体（APR、电商等），保证权限和数据归属清晰。
5. **第五步：沉淀 skill**
   - skill = 把**胜任且优秀**员工每天要做的事情提炼成标准 SOP 工作流（不以不胜任员工的做法为蓝本）。
   - 沉淀后形成日常巡检内容，AI 自动提醒、自动检查、智能体之间互相检查。

## 三、报表「三层结构」（格式硬要求）

所有报表（日/周/月）统一三层：

1. **表头**：报表的字段结构（表头是什么、呈现哪些指标）。
2. **中间层**：各业务板块的具体数据和过程指标、过程数据。
3. **总结层**：重点事项的总结——推进执行、风险控制、下一步计划。

补充要求：参考大公司报表逻辑；报表 = 透视表 + 具体分表（5 块表）+ 总结；以利润为导向，所有板块数据最终服务于公司利润最大化。

## 四、经营管理智能体架构（层级示例）

- 公司级：**经营总智能体**（统一入口，避免各板块权限/口径混淆）。
- 职能层：销售职能体 / 运维 / 人事行政 / 财务审计风控（四职能，可扩展）。
- 销售职能体细分（以 APR 为例）：
  - APR 运营职能体 → 经营分析、日常 SOP 巡检、营销助手、销售员 AI 智能体（话术支持）。
- 电商板块同样按：经营分析 → 日常 SOP 巡检 → 营销推广（标准化 + 内容营销/投放；AI 生成图片、短视频、直播内容）。
- 3PP 板块按同一逻辑套用。
- 原则：从总到分（总部 → 渠道 → 部门 → 促销员/店员），一层层嵌到最小业务单元，当前三层够用，未来可再细分。

## 五、skill 的定义

- 把优秀员工每天该做的事归纳为标准 SOP 工作流（如销售员：前端接待 → 日常动作 → 数据抓取 → 巡检内容）。
- skill 是岗位级技能包，供智能体调用，也用于培训和自动检查（谁没学、谁没做，自动识别）。

## 六、数据来源与成本约束（重要）

- 当前数据源主要是**极客云 API**（录音中亦称「集合云/集控」）。
- 成本问题：极客云 API 收费，测试一天约需数千条额度；套餐档位：一年约 2.9 万、3 万不限、10 万条 1000 元等；电商侧一年约 50 万条、已用约 36 万条，测试额度不够。
- 老板倾向：能直接对接的 API 优先；一天取一次；数据建起来后不依赖外部软件，可让 AI 自写。
- 爬虫方案消耗高，不作为首选。
- 前期可先用模拟数据，不急于接真实系统。

## 七、老板对落实责任人的「三件事」

1. **全程参与**财务和商务制定表格内容、形式和最终呈现，必须理解数据来源、数据逻辑和呈现目的（不理解底层逻辑等于白做）。
2. 模板确定后，**保证数据从哪取、用什么工具抓、哪些需要人工确认和补充**。
3. 前两点做好后，才**搭建经营竞争力框架和 skill**（第四、第五步是后续要研究的重点）。

## 八、团队理解与分工确认（录音中员工复述）

- 第一步：以利润为导向，把各板块表头（前端到后端）整理出来。
- 第二步：确认表头内各项数据来源（极客云 API / 办公台 / 人工）与日、周、月取数周期。
- 第三步：确认取数工具（Codex GPT / 小龙虾 / 工作流）。
- 第四步：用 AI 建立经营管理智能体，从总部总智能体 → 渠道 → 部门 → 促销员逐层落地。
