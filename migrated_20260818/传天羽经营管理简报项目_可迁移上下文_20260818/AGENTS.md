## 不可违反的约束

- `02-核心源资料/江苏传天羽经营管理全景框架_0817周会版.html` 是内容主骨架。
- HTML 的 6 个一级层、18 个二级模块、54 个三级节点不得删除或遗漏，只能规范表述和补充。
- 会议纪要与第五版 Excel 只能用于补充，不得覆盖 HTML 主骨架。
- Apple 电商只包含京东羽通、苏宁啟韬，不含天猫。
- 天猫渠道目前只属于 Shure 电商，Shure 电商包含京东官方旗舰店和天猫官方旗舰店。
- 四大经营板块为 APR 门店、Apple 电商、Shure 电商、3PP/渠道分销。
- 不得把内容营销、综合办/人事、财务、采购/商务重复计入销售板块。
- 缺失数据必须显式标记为“暂估 / 待确认 / 缺失”，禁止静默补数。
- 日报看异常和当天动作，周报看变化、差距和闭环，月报看经营质量与资源配置。
- 风险和重点事项必须有责任、时限、下一节点、措施和关闭证据。

## 0817 录音会议补充约束（06-会议录音转写）

- 报表（日/周/月）统一「三层结构」：表头 / 业务板块数据与过程指标 / 重点事项总结（推进、风控、下一步）。
- 经营管理智能体按四职能层搭建：销售 / 运维 / 人事行政 / 财务审计风控；销售职能体下按板块细分智能体。
- skill = 把胜任且优秀员工的日常工作提炼为标准 SOP 工作流，不作为不胜任员工的写照。
- 数据主抓销售、采购、库存三类；取数一天一次、API 直连优先；极客云 API 收费且额度受限，需财务确认。
- 抓取数据必须有人工审核确认流程，禁止静默自动采信。

## 工作方式

- 修改现有成果前先确认任务是否仍属于“框架阶段”。
- 新增内容应说明来源、管理目的、呈报周期、责任端口和下钻载体。
- 指标阈值和具体责任人尚待老板批复，未经确认不要写成正式公司制度。
- 如恢复网站建设，应以最终第四版 Excel 为信息架构基线，而不是沿用旧网页内容直接扩展。
