# 传天羽高管经营驾驶舱 V4

## 一、设计目标

本版保留 V3 已有数据、业务逻辑、时间切换、重点事项、老板批复、风险控制和 AI 分析功能，对整站信息架构与视觉层级重新设计。

界面定位为“高管驾驶舱”：先看结论，再看异常，最后看责任人与下一步动作。

## 二、核心调整

- 使用固定深色左侧导航，将经营、管理、事项和风控明确分区。
- 顶部页眉随页面切换，直接提示当前管理目标与阅读重点。
- 首页按“经营结论 → 待决策事项 → 核心指标 → 预警 → 模块入口”组织。
- 降低装饰性色彩和图标密度，改为中性灰白底色、深色信息区与少量状态色。
- 数据表格强化表头、行间距、数字对齐和横向滚动，长表更适合管理层阅读。
- 经营、管理、重点事项和风控页建立统一卡片规则，同时保留不同的阅读语义。
- 完成桌面端、平板和手机端自适应，手机端导航改为底部快捷入口。

## 三、使用方式

Windows 电脑可直接双击 `启动看板.bat`，或在当前目录执行：

```text
python app.py
```

然后访问 `http://127.0.0.1:8003`。

## 四、主要文件

- `templates/index.html`：看板页面与交互逻辑。
- `static/executive-v40.css`：V4 整站视觉与响应式规则。
- `app.py`：页面、数据和 AI 接口服务。
- `data.json`：前端主数据源。
