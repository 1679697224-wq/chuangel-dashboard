# 传天羽经营看板项目

江苏传天羽 经营管理简报 · 老板确认版看板 + 登录权限系统

## 一、项目结构
| 目录/文件 | 说明 |
|---|---|
| `老板确认看板/boss-dashboard-v6.html` | 老板确认版看板（单文件，核心交付物） |
| `登录权限系统/` | 6 角色登录门户 + 数据上传后端（纯 Python 标准库） |
| `吉客云数据/` | 销售/库存/客流聚合结果与数据摘要 |
| `看板版本存档/` | 每次改版的历史存档 + 版本清单.md（进度记录） |
| `dsh_keys/` | 取数/聚合脚本（私钥不入库） |
| `阿里云ECS部署指南.md` | 部署说明 |
| `同事填写指引-流量转化.md` | 各负责人填写流量/转化的操作指引 |
| `项目进度.md` | 项目进度时间线（本文件为跟进入口） |
| `caixiao/` | 采销经营驾驶舱 V1（独立运行，与现有总部看板共存） |

采销驾驶舱的启动、接口和 Review 说明见 [`caixiao/README.md`](caixiao/README.md)。本轮没有修改现有总部看板、登录系统或客流爬虫正式配置。

## 三、协作方式
1. 本项目用 Git 管理，所有人 `git clone` 后即可跟进进度（每次改动都有记录）；
2. 各板块数据（流量/转化/目标）由对应负责人按《同事填写指引》维护，或在登录系统工作台上传；
3. 看板更新由主负责人校验后部署上线。
